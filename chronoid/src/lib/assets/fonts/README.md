# Neue Haas Unica

Police sous licence Monotype : les fichiers ne sont pas fournis dans le dépôt.
Une fois la licence web achetée, déposez ici les fichiers `.woff2` en respectant ces noms :

| Fichier                            | Graisse |
| ---------------------------------- | ------- |
| `NeueHaasUnica-Light.woff2`        | 300     |
| `NeueHaasUnica-Regular.woff2`      | 400     |
| `NeueHaasUnica-Italic.woff2`       | 400 it. |
| `NeueHaasUnica-Medium.woff2`       | 500     |
| `NeueHaasUnica-MediumItalic.woff2` | 500 it. |
| `NeueHaasUnica-Bold.woff2`         | 700     |

Le site les détecte au build (`BrandFonts.svelte`) : rien d'autre à modifier.
Tant qu'ils sont absents, le site s'affiche en Inter, sans erreur.
Le site utilise surtout Regular (texte) et Medium (titres) : ce sont les deux indispensables.
